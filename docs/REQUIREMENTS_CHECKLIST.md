## Known limitations

* Matching via API Gateway is subject to the 30 s HTTP API timeout; very large batches would need async invocation (documented in `OPTIMIZATION.md`).
* `POST /api/uploads` has no end-user authentication.
* Extraction rules are tuned to the three configured pages. Segment-specific criteria on one page are collapsed to the strictest value.
* The n8n env-access setting lets workflow editors read n8n's environment (`SECURITY_AND_COST.md`).
